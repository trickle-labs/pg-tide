# v0.59.0

> **Status:** Planned
> **Theme:** Bidirectional hardening and validation
> **Size:** Medium-large
> **Depends on:** v0.58.0
> **Detailed plan:** [`plan_outbound.md`](../plan_outbound.md)

v0.59.0 validates the complete seven-route product rather than adding another
connector. The release runs forward and reverse pipelines together under both
supported build profiles and proves direction-aware catalog discovery,
ownership, status, metrics, health, delivery receipts, support bundles,
shutdown, tenant isolation, and adjacent-version upgrades. It also measures
forward regressions and reverse throughput, latency, memory, connection use,
lag recovery, webhook saturation, and drain time in the reference environment.

This release absorbs the useful parts of the former v0.55.0 independent
validation scope after repeating them against the expanded product. Production
pilots, independent correctness, security, operations, performance, and API
reviews, ownership succession, runbook drills, artifact verification, and a
full release rehearsal bind to the exact v0.59.0 candidate. No result collected
for the old outbound-only candidate counts as proof for an inbound route.

v0.59.0 is complete when all connector support gates and required tests are
green with zero unresolved blockers, the closed route matrix is consistent in
code and generated artifacts, the release evidence index is closed, and the
roadmap records measured outcomes. Completion does not trigger a v1.0.0 release;
future v0.x work continues until a separate roadmap decision resumes v1
planning.
