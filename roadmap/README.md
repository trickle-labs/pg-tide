# Release roadmap

These short pages state release scope and status. Each release page links to
the detailed implementation plan that governs it.

The active sequence after v0.54.0 is v0.55.0 through v0.59.0, governed by
[`plan_outbound.md`](../plan_outbound.md). v1.0.0 and its release-candidate
series are postponed indefinitely and have no target date.
