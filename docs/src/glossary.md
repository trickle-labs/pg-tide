# Glossary

The canonical project glossary is maintained at the repository root as
[GLOSSARY.md](https://github.com/trickle-labs/pg-tide/blob/main/GLOSSARY.md). It is the shared Ubiquitous Language for
pg_tide code, SQL APIs, documentation, dashboards, and incident reports.

Keep this page in the documentation navigation so readers can find the
glossary from the book, but edit the root file when terminology changes. The
root file deliberately uses longer entries to explain how neighboring terms
fit together and which guarantees each term does, and does not, provide.
